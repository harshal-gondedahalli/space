# SPACE — Junior Astronaut Mission

A browser-based educational spaceflight game. Build a rocket, run a launch countdown, control a simulated flight, select a destination, and complete an astronaut surface mission.

## Play
Open `index.html` in a modern browser, or enable GitHub Pages:
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Visit https://hrashal-gondedahalli.github.io/space/

All launches, telemetry, planets, and astronaut activities are simulated for learning. This game does not control real spacecraft or rockets.
